# mcpbus releases

Binary releases for [mcpbus](https://getmcpbus.com) — the MCP server that connects Claude to your SQL databases.

## Install

```powershell
irm https://getmcpbus.com/install.ps1 | iex
```

Or download the installer directly from the [releases page](https://github.com/offe81/mcpbus-releases/releases).
